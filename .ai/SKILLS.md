# Skill Directory

| [Authoring Blocks](skills/authoring-blocks/SKILL.md) | generated plugins | Creating or modifying blocks, block.json, entries, attributes |
| [Styles](skills/styles/SKILL.md) | generated plugins | Writing CSS within the enforced budget; debugging lint failures |
| [Troubleshooting](skills/troubleshooting/SKILL.md) | framework + plugins | Build failures, dev-server issues, zip/CI problems |
